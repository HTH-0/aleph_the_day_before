# THE_DAY_BEFORE

> **"어제 하루 동안 생성된 공개 GitHub 저장소 수를 매일 기록하고, 데이터가 오지 않을 때도 정직하게 설명하는 대시보드"**

**주소:** [aleph-the-day-before.vercel.app](https://aleph-the-day-before.vercel.app/)

---

## 프로젝트 철학

* **왜 '오늘'이 아닌 '어제'인가요?**
오늘 생성된 저장소 수는 측정 시점에 따라 계속 달라집니다. 이미 마감된 '어제'를 기준으로 삼아야 흔들리지 않는 명확한 비교가 가능합니다. *(GitHub 검색 인덱스 갱신 특성상 소급 변경될 수 있으며, 이는 화면 상세에 투명하게 안내합니다.)*
* **정직함이 곧 기능입니다**
외부 API 호출 실패 시 임의의 가짜 값을 채워 넣지 않습니다. 마지막 정상 수집 값을 안전하게 보존하고 지연 상태를 명확히 표시합니다.

---

## 30초 퀵 스타트

1. **실시간 값 확인**: 접속 즉시 어제 집계된 GitHub 저장소 수와 전일 대비 증감이 표시됩니다.
2. **검증 및 상세 내역**: `상세` 버튼을 눌러 실제 API 엔드포인트, 응답 상태, Rate Limit 잔여량을 확인합니다.
3. **히스토리 탐색**: 잔디 히트맵 칸에 마우스를 올리면 하단 표에서 해당 날짜의 실제 기록이 강조됩니다.
4. **장애 대응 시뮬레이션**: 하단 `FALLBACK`을 열고 5가지 실패 시나리오를 직접 실행해 봅니다.

## 주요 기능 구성

| 구역 | 역할 | 핵심 포인트 |
| --- | --- | --- |
| **CURRENT (헤드라인)** | 어제 생성된 저장소 수 실시간 조회 | 실시간 조회, 전일 대비 증감, 호출 메타데이터 상세 토글 |
| **HISTORY** | 누적 데이터 시각화 | 동적 잔디 히트맵, 4종 요약 통계 카드, 추이 차트, 원본 기록 표 |
| **FALLBACK** | API 장애 대응 인터랙티브 실험실 | 5가지 실패 시나리오 재현, 타임라인 표기, 데이터 복구 과정 검증 |
| **HEADER** | 상태 모니터링 및 인터랙션 | 실시간 수집 상태 고정 배지, 인터랙티브 커밋 해시 애니메이션 |

## 장애 대응 시뮬레이터 (FALLBACK)

실제 외부 API 장애 상황에서 시스템이 데이터를 어떻게 보호하고 표시하는지 직접 테스트할 수 있습니다.

* **5가지 실패 시나리오**: 느린 응답(Timeout) · 인증 실패(401) · 호출 제한(Rate Limit) · 네트워크 단절(Offline) · 응답 스키마 변경
* **데이터 격리 원칙**: 시뮬레이션에서 생성된 합성(Fixture) 데이터는 실제 기록(`HISTORY`)에 절대 반영되지 않으며 새로고침 시 초기화됩니다.

## UI/UX 디테일

* **Dynamic Heatmap**: 기록된 날 수만큼만 잔디 칸을 렌더링하여 빈 슬롯 없는 완성도 제공
* **Auto Font Scaling**: 큰 숫자가 뷰포트를 벗어나지 않도록 실제 렌더링 폭을 측정해 폰트 크기 자동 조절
* **Git Metaphor Interaction**: 로고 호버 시 16진수 커밋 해시 슬롯머신 감속 애니메이션 적용
* **Role-based Typography**: 가독성을 위한 Manrope/Inter 본문과 코드 메타데이터용 JetBrains Mono 분리 적용

---

## 운영 원칙

* **No Fake Data**: 실패 상태를 숨기기 위해 임의의 대체 값을 지어내지 않습니다.
* **Integrity**: 화면에 렌더링되는 모든 수치는 보존된 원본 값과 일치합니다.
* **Privacy by Design**: 별도의 로그인이나 개인 식별 정보, API 비밀키를 수집하거나 저장하지 않습니다.
